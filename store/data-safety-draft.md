# مسودة مراجعة أمان البيانات

هذه قائمة للعمل على استبيان Play Console، وليست تصريحًا نهائيًا. يجب مراجعة سجلات الاستضافة وعقود وسياسات الجهات الخارجية قبل الإرسال.

| المجال | السلوك الحالي | المراجعة المطلوبة |
|---|---|---|
| حسابات وأسماء وبريد | لا يوجد تسجيل أو حساب | تأكيد عدم إضافة دخول لاحقًا |
| نوتات ومفضلة وإعدادات | محلية؛ لا رفع تلقائي | ملفات المشاركة تُرسل للوجهة التي يختارها المستخدم |
| أسئلة AI وسياق المحادثة | تُرسل إلى Vercel وGamaliel | بيانات المستخدم المرسلة، الاحتفاظ، الغرض، المعالجة المؤقتة |
| IP وبيانات الاتصال | تصل للمزود عند طلب خدمة | سياسات Vercel/Gamaliel/Tasbeha/SoundCloud وسجلاتهم |
| إعلانات وتحليلات | لا SDK إعلانات أو تحليلات خاص بالتطبيق | مراجعة تشغيل SoundCloud والخدمات الخارجية قبل إعلان عدم وجود إعلانات |
| أذونات | Internet فقط؛ ملف يختاره المستخدم؛ مشاركة من Cache | التحقق من merged manifest للإصدار النهائي |
| حماية النقل | HTTPS إلى الخدمات الخارجية | مراجعة كل مصدر مستقبلًا |
| حذف البيانات | حذف النوتات أو مسح بيانات التطبيق؛ لا حساب خارجي | إجراءات مزود AI للطلبات التي تصل إليه |

سياسة الخصوصية: https://amegoo.vercel.app/privacy.html . الجمهور المقترح للمراجعة هو المراهقون والبالغون؛ لا تُعلن النسخة موجهة للأطفال دون مراجعة متطلبات Families ومزودي AI والمحتوى الخارجي.

إشعارات يومية اختيارية محلية: POST_NOTIFICATIONS عند التفعيل، وRECEIVE_BOOT_COMPLETED لإعادة الجدولة. لا توجد خدمة Push ولا تُرسل تفضيلات الإشعار أو نصوص الآيات لخادم.

## إفصاحات محفوظة في Play Console — ١٥ أكتوبر ٢٠٢٦

سياسة الخصوصية: https://amegoo.vercel.app/privacy.html (تم التحقق من HTTP 200). الوصول: لا يلزم حساب أو دفع. التطبيق غير حكومي، ولا يقدم خصائص مالية أو صحية. تم التصريح بوجود إعلانات محتملة لأن SoundCloud يوضح أن المشغل المضمّن قد يعرض إعلانًا صوتيًا عند تفعيل صاحب التسجيل للربح: https://help.soundcloud.com/hc/en-us/articles/115003447287-Ads-on-SoundCloud- . لم تتم إضافة شبكة إعلانات خاصة بالتطبيق. وُسمت الأيقونة والبانر كأصول معدلة بالذكاء الاصطناعي؛ صور الهاتف الأربع لقطات فعلية من واجهة أندرويد مع حواف محايدة لضبط المقاس فقط. تظل بيانات الأمان والتصنيف العمري والجمهور واحتفاظ مزودي AI ببيانات المحادثة بحاجة لاستكمال قبل الإصدار العام.

## تحديث Play Console — ١٥ أكتوبر ٢٠٢٦

تم حفظ استبيان IARC وأصبح إعداد التطبيق مكتملًا ٩ من ١١ بندًا. راعى الاستبيان الإشارات النصية في الكتاب المقدس للعنف والذبائح والعلاقات والخمر، مع عدم وجود مشاهد مصورة أو ألعاب. النتائج المحسوبة المعروضة: ESRB Teen، USK 12+، PEGI 3، وIARC 3+؛ وقد تختلف النتائج عند مراجعة الجهات المختصة. المتبقي: الجمهور المقصود (بانتظار تحديد الناشر) وأمان البيانات.

حُفظت مسودة أمان البيانات: يوجد نقل بيانات، النقل مشفر، لا إنشاء حساب أو دخول بحساب خارجي، ولم يُدّع وجود مسار حذف بيانات الخادم. تحديد أنواع البيانات واستعمالاتها لم يُرسل نهائيًا. سياسة Gamaliel العامة تذكر الاحتفاظ بالأسئلة والمحادثات لمدة تصل إلى سنة، ويجب تأكيد تطبيقها على API قبل الإفصاح النهائي: https://gamaliel.ai/site/privacy-policy . سياسة SoundCloud تشمل المشغلات المضمنة والتحليلات. لا يصح التصريح بأن التطبيق لا يجمع أي بيانات. قناة بلاغات المساعد المركزية لم تُجهز بعد، وهي من متطلبات تجهيز الإصدار العام.

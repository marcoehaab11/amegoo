طريقة الرفع
1. ارفع index.html وvercel.json وkhoolagy.svg في جذر مستودع amegoo، ثم اضغط Commit changes.
2. في Vercel اختر Add New > Project ثم استورد amegoo.
3. Framework Preset: Other. Root Directory: جذر المستودع. لا يحتاج المشروع Build Command. Output Directory: .
4. اضغط Deploy.

حالة الخولاجي
تم ربط الزر بواجهة داخل التطبيق، والأيقونة SVG مكتوبة داخل HTML.
النصوص لم تُضف بعد: يلزم تحديد القداس وإرسال النص أو الطبعة المعتمدة.
في index.html ابحث عن KHOOLAGY_TEXTS؛ كل paragraphs مصفوفة فقرات نصية محلية.
هذه الواجهة لا تطلب نصوص الخولاجي من موقع خارجي.
باقي التطبيق الأصلي ما زال يستخدم مصادر خارجية للخطوط والأيقونات وبعض القراءات.
تم التحقق من صحة صياغة JavaScript؛ لم يُختبر تشغيل الواجهة في المتصفح.
